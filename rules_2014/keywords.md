# 2014 年 3 月關鍵字與標籤

以下規則涵蓋 2014 年 3 月 Basic 與 Classic／Expert 卡牌會使用的關鍵字。部分關鍵字在 Basic 很少或沒有出現，但已存在於當時的 Classic 玩法。

> **暫時排除項目：** Choose One（抉擇）與 Secret（秘密）是本規則刻意暫時拿掉的效果。之後補入相關卡牌時，應先改寫為功能相近的固定單一效果，不要直接假設已支援這兩套規則。

## 戰鬥關鍵字

- **Taunt（嘲諷）**：敵方攻擊必須優先指定具有 Taunt 的手下。
- **Charge（衝鋒）**：手下召喚的當回合可以攻擊。
- **Windfury（風怒）**：手下每回合可以攻擊兩次。
- **Freeze（凍結）**：角色不能攻擊；解除的當回合仍不能攻擊。
- **Divine Shield（聖盾）**：抵消下一次傷害，之後移除。
- **Stealth（潛行）**：不能被敵方直接指定或攻擊；攻擊後失去潛行。
- **Spell Damage（法術傷害）**：增加法術造成的傷害，不增加攻擊或一般戰吼造成的傷害。

## 出牌關鍵字

### Battlecry（戰吼）

手下從手牌成功打出並召喚到場上後觸發一次。若場上已滿、手下沒有成功進場，戰吼不會觸發。

### Deathrattle（死亡之聲）

手下死亡並離開場上後觸發一次。死亡之聲不是只有被摧毀才會觸發；任何造成手下死亡的方式都可能觸發它。

### Combo（連擊）

本回合在該卡之前已打出另一張牌時成立。英雄技能、攻擊與結束回合不算打出牌。連擊效果通常出現在 Rogue 的 Classic 卡牌。

### Overload（過載）

卡牌打出後，下一個己方回合有指定數量的 Mana 水晶不能使用。多張 Overload 的數值相加；本回合仍可使用剩餘 Mana。

### Enrage（激怒）

手下受傷時啟用指定效果，恢復到滿生命時停止。Enrage 不等於一次性 Buff；條件失效時效果也失效。

## 其他關鍵字

### Silence（沉默）

移除手下目前由卡牌文字、關鍵字、Aura 或 Buff 提供的效果；不會移除基本攻擊力、基本生命值、種族，也不會把已受到的傷害恢復。卡牌文字若明確指定 Silence 的範圍，以該文字為準。

## 種族

種族是手下的牌面屬性，不是 Buff。2014 年 3 月 Basic／Classic 會用到的主要種族包括：

- **Beast（野獸）**。
- **Murloc（魚人）**。
- **Demon（惡魔）**。

2014 年 3 月尚未有後來的 Mech 卡牌系統，因此本規則不建立 Mech 種族規則。

種族條件只在卡牌文字要求時生效，例如 Beast Buff、Murloc Aura、Houndmaster 的目標限制或 Kill Command 的傷害條件。
