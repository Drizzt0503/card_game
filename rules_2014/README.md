# Hearthstone 2014 年 3 月規則

本目錄描述 2014 年 3 月 Hearthstone 上市初期的概念玩法，不以目前專案程式、資料欄位或 Engine 行為為準。

## 規則範圍

本規則包含：

- Basic Set。
- Classic／Expert Set。
- 九個職業、英雄與英雄技能。
- 2014 年 3 月已存在的通用卡牌規則與關鍵字。

本規則不包含：

- Curse of Naxxramas。
- Goblins vs Gnomes。
- 2014 年 3 月之後新增的卡牌、關鍵字與平衡修改。
- 後來才出現的 Mech、Spare Parts、Magnetic、Discover 等規則。

這裡的版本是遊戲 2014 年 3 月上市初期，不是 Blizzard 後來以 2014 年 6 月版本建立的 Classic 模式。Blizzard 的 Classic 說明明確指出兩者存在差異，例如 Warsong Commander、Holy Smite 與 Leeroy Jenkins 的卡牌文字或數值不同。[Blizzard Classic 說明](https://hearthstone.blizzard.com/en-us/news/23620129)

## 核心目標

每位玩家控制一名英雄與一副牌。玩家使用逐回合增加的 Mana 打出手牌、召喚手下、施放法術、裝備武器、使用英雄技能並進行攻擊；將敵方英雄生命值降至 0 即獲勝。

卡牌文字是規則的一部分。除非卡牌文字明確改變一般規則，否則遵守本目錄的通用規則。
