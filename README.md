# Card Game MVP

目前版本是單機雙人 CLI 原型：兩名玩家先選擇職業，再輪流使用各自的 30 張預設白板手下牌組對戰。

## 執行

在專案根目錄執行：

```bash
python -m src.cli.main
```

## 目前規則

- 每副牌 30 張，由 15 種白板手下各放 2 張組成。
- Hero 初始 30 HP。
- 每回合增加 1 Mana，最多 10 Mana。
- 每回合開始抽 1 張牌。
- 場上最多 7 個手下，手牌最多的規則尚未實作。
- 手下出場當回合不能攻擊。
- 手下可以攻擊敵方 Hero 或敵方手下。
- Hero HP 歸零時遊戲結束。
- 目前 15 種卡牌全部標記為中立，因此選擇不同職業時牌組內容暫時相同。
- 非傳說牌最多放 2 張；傳說牌未加入，但牌組產生器已預留最多 1 張的規則。
- 開始遊戲時可以選擇 Player 2 由真人或基本 Rule-based AI 控制；AI 職業會隨機選擇。
- AI 回合會在背景執行，AI 的公開行動 Log 會在下一個玩家回合顯示。

攻擊時，目標輸入 `0` 代表敵方 Hero；輸入 `1` 以上代表敵方場上手下的編號。

這一版暫時不包含法術、英雄技能、武器、關鍵字、AI、RL 與牌組編輯。
## Windows executable

在 Windows 環境中雙擊 `build_windows.bat`，或在命令列執行：

```bat
build_windows.bat
```

完成後執行：

```text
dist\card_game.exe
```

目標電腦不需要另外安裝 Python。打包需要在 Windows 環境執行，且建議使用與開發環境相同的 Python 版本。
